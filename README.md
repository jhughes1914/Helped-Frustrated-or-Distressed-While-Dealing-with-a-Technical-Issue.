# Helped Frustrated or Distressed Users While Dealing with Technical Issue

## Objective

Provide calm, clear, and empathetic support to users who are frustrated or distressed by technical issues. Focus on understanding their concerns, guiding them through solutions in a patient and approachable manner, and ensuring they feel heard and confident by the end of the interaction.



### Situation
At my current help desk role, I support end users who frequently work under high pressure. One end user called in extremely frustrated because their remote deposit check scanner (remote device allow automatic deposit into checking account) kept disconnecting, delaying and preventing them from depositing checks causing negative chain reaction within their accounting.

### Task
My task was not only to resolve the technical issue but also to calm the situation so they could continue without added stress.

### Action
I acknowledged their frustration, slowed the conversation down, and gathered details. I discovered that their scanner drivers are usually not running in which prompting a form of error message that their device is disconnected.

### Results 
End users are able to utilize remote deposit check scanner after restarting drivers and performing an initialization test to diagnose any potential issues that is causing the device to be disconnected. Receiving _"Status Success"_ and a green light indicator on their scanner are signs the scanner is connected and working.


### Tools Used
- Windows 10 or 11, and MacOS 10.14+
- Memory: 2 GB RAM
- Hard Drive: 1.5 GB
- Browser: Chrome, Edge, and Safari
- Device: CX30 Digital Check Express and Panini 

## Steps
Windows:
- Open Program List
- Select _Remote Deposit Web Client_ folder
- Select _Restart Web Client Driver_
- Return to _Remote Deposit Folder_
- Select _Web Client Diagnostic_
- Select _Initialize Scanner_ (some instances it may state: _Test Scanner_ or _Proceed to Standard Diagnostic Page_ it will result to Initialize Scanner)
- Status Result

MacOS:
- Open Finder
- Select Applications
- Select _Remote Deposit Web Client_ folder
- Select _Restart Web Client Driver_
- Return to _Remote Deposit Folder_
- Select _Web Client Diagnostic_
- Select _Initialize Scanner_ (some instances it may state: _Test Scanner_ or _Proceed to Standard Diagnostic Page_ it will result to Initialize Scanner)
- Status Result
